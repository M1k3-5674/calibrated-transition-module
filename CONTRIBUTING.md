# Contributing

This repo is source-available. The project stays with Kevin Michael Lent.

## How to stay in the official line

1. Fork.
2. Open an issue first if the change is large.
3. Send a pull request to `main`.
4. Keep LICENSE, NOTICE, and the copyright line.

By opening a pull request you grant the copyright holder the right to
include your patch in later free and paid releases. You keep copyright
in your own patch.

## Derivative notice

If you publish a public fork or port, open an issue titled
`Derivative notice` and paste the URL. That is required by the license.
